# 迁移清单

本文逐个目录对照 Material Maker（导入时的提交 `7d6daae`，见 [NOTICE.md](../NOTICE.md)）的源码和本项目的对应实现。导入之后，节点库等数据已成为本项目自己维护的源码（`library/`），不再与 Material Maker 同步。

状态：**完成**（功能齐全，个别出入写在备注里）、**部分**（主体可用，缺的写在备注里）、**不适用**（只在 Godot 桌面程序里有意义）、**按需求不迁移**、**未移植**。
