# 命令行

`material-pro` 不打开编辑器就能导出材质、渲染节点，用法与 Material Maker 的命令行导出（`material_maker/parse_args.gd`）一致，可以写进构建脚本或批量处理整个文件夹。

## 安装与运行

```bash
npm install
```

```bash
npm run build
```

在项目目录里用 `npm run cli -- <参数>` 或 `node bin/material-pro.mjs <参数>` 运行。`npm link` 之后可以在任何目录直接用 `material-pro`。

命令行在无界面的 Chromium 里运行引擎（需要 WebGL2）：有 `dist/`（`npm run build` 的结果）时直接用它，没有时通过 Vite 从源码运行，第一次会慢几秒。浏览器由 Playwright 提供；如果提示找不到浏览器，运行一次：

```bash
npx playwright install chromium
```

## 命令

### export：导出材质

```bash
material-pro export materials/bricks.ptex --target "Godot/Godot 4 Standard" --size 1024 --out build/textures
```

| 选项 | 说明 |
| --- | --- |
| `-t`, `--target T` | 导出目标，默认 `Godot/Godot 4 Standard`。可以是材质自带的导出配置，也可以是 `cocos`、`glb`、`m3e`、`maps` 之一（见下表）。名字不完全一致时选最相近的一个并提示，和 Material Maker 一样 |
| `-s`, `--size N` | 贴图尺寸（像素，16–8192）。默认用材质自己的尺寸 |
| `-o`, `--out DIR` | 输出目录，默认当前目录。`--output-dir` 同义 |
| `--output-file T` | 文件名前缀模板：`%f` 文件名（不含扩展名），`%N` 材质名，`%n` 小写并用下划线连接的材质名。默认 `%f` |
| `--name NAME` | 材质名，用于 `%N`、`%n` 和 m3e 材质。默认是文件名 |
| `--glb-shape S` | glb 用的模型：`plane`（默认）、`sphere`、`cube` |
| `--zip` | 每个工程打成一个 zip，而不是散文件 |
| `--no-export-nodes` | 不导出工程里的“导出”节点 |
| `--m3e-tile PX` | m3e：100% 缩放时一个平铺单元的尺寸，默认 160 |
| `--m3e-resolution PX` | m3e：图片尺寸，默认 `min(size, 512)` |
| `--m3e-light AZ,EL` | m3e：烘焙用的光，方位角和高度，默认 `315,45` |
| `--m3e-format F` | m3e：`webp`（默认）或 `png` |
| `--m3e-no-raw` | m3e：不带 PBR 原始贴图 |
| `--m3e-project` | m3e：附带工程，以后可以再编辑 |
| `-q`, `--quiet` | 只输出错误 |

文件名可以带 `*`，一次导出多个工程：

```bash
material-pro export "materials/*.ptex" -t Unity/URP -o build/unity
```

Material Maker 的写法也能用：

```bash
material-pro --export materials/bricks.ptex -t "Unreal/Unreal Engine 5" -o build --output-file %n
```

### 导出目标

材质自带的导出配置（静态 PBR 材质）：

| 目标 | 产出 |
| --- | --- |
| `Godot/Godot 4 Standard`、`Godot/Godot 4 ORM`、`Godot/Godot 3 Spatial` | 贴图和 `.tres` 材质 |
| `Unity/3D`、`Unity/URP`、`Unity/HDRP` | 贴图、`.meta` 和 `.mat` 材质 |
| `Unreal/Unreal Engine 5` | 贴图和建材质用的 `.py` 脚本（脚本需要 Material Maker 安装目录里 `export/mm.py` 这个辅助模块） |
| `Unreal/Unreal Engine 4` | 贴图和 `.mm2ue`（内含手动建材质的步骤和着色器代码） |
| `Blender` | 贴图（颜色为 PNG，粗糙度、金属度、置换、遮蔽为 EXR） |
| `GLTF/Plane` | 带材质的平面 glTF |

本项目增加的目标：

| 目标 | 产出 |
| --- | --- |
| `maps` | 全部标准贴图：albedo、orm、emission、normal（OpenGL）、normal_dx（DirectX）、height、depth、ao、metallic、roughness、sss |
| `cocos` | Cocos Creator 3.x 的材质文件夹：`.mtl`、贴图和 `.meta` |
| `glb` | 带材质的二进制 glTF 模型 |
| `m3e` | m3e-canvas-pro 的材质包 `.m3e-material.json`，格式见 [m3e-material.md](m3e-material.md) |

用 `list-targets` 查看某个工程能用哪些目标。

### list-targets：列出导出目标

```bash
material-pro list-targets materials/bricks.ptex
```

第一行是材质类型和尺寸（加 `-q` 时不输出），之后每行一个目标名，可以直接给脚本使用。

### render：渲染一个节点的输出

```bash
material-pro render materials/bricks.ptex --node colorize_0 --output 0 --size 1024 --out bricks_color.png
```

| 选项 | 说明 |
| --- | --- |
| `--node PATH` | 节点名，或穿过子图的路径（如 `graph_2/blend_1`） |
| `--output I` | 输出序号，默认 0 |
| `-s`, `--size N` | 图片尺寸，默认 1024 |
| `-o`, `--out FILE` | `.png`、`.jpg` 或 `.webp` |

## 退出码

| 退出码 | 含义 |
| --- | --- |
| 0 | 完成 |
| 1 | 有工程导出失败（其他工程照常导出），或渲染失败 |
| 2 | 用法错误：未知选项、缺少参数、文件不存在 |
| 3 | 无法启动浏览器或 WebGL2 |

## 测试

```bash
npm run test:cli
```

在示例工程上把每类目标导出一遍并检查结果（文件、尺寸、格式），也检查 `list-targets`、`render` 和错误情况。导入真实引擎的检查见 [本地验证.md](本地验证.md)。
