# Material Pro 用户手册

Material Pro 是一个在浏览器里运行的程序化材质编辑器：用节点图生成贴图和 PBR 材质，在 2D、3D 中实时预览，再导出给 Blender、Unity、Godot、Unreal Engine、Cocos Creator、glTF 和 m3e-canvas-pro 使用。它也可以在 3D 模型上分层绘制材质。

本手册按界面顺序介绍全部功能。界面语言可以在“偏好设置 → 一般 → 语言”切换，也可以在网址后加 `?lang=zh` 或 `?lang=en`。

## 1. 基本概念

### 1.1 节点与节点图

一个材质由**节点**连成的**节点图**计算出来。每个节点有输入端口（左侧）、输出端口（右侧）和参数。数据从左往右流：例如“噪波”节点生成灰度图，接进“着色”节点变成彩色，再接进“材质”节点的“反照率”输入。

所有节点都在 GPU 上逐像素计算，没有分辨率限制：同一张图可以按 512×512 预览，再按 4096×4096 导出。

每个工程有一个**材质节点**（默认是“静态 PBR 材质”），它的输入就是最终的贴图通道：反照率、金属度、粗糙度、自发光、法线、环境光遮蔽、深度、次表面散射等。3D 预览和导出都以它为准。

### 1.2 端口类型

端口的颜色表示它传递的数据类型。只有兼容的类型才能相连；灰度、颜色、RGBA 之间会自动转换。

| 类型 | 含义 |
| --- | --- |
| 灰度 | 一个数值，通常在 0–1 之间（高度、遮罩、粗糙度……） |
| 颜色 | RGB 颜色 |
| RGBA | 带透明度的颜色 |
| SDF2D | 2D 有向距离场：到形状边界的距离，内部为负 |
| SDF3D / 带颜色的 SDF3D | 3D 有向距离场，用于光线步进物体 |
| 3D 纹理（灰度 / 彩色） | 在 3D 空间中定义的纹理，可用于 3D 材质 |
| 填充 | 每个封闭区域的包围盒信息，配合“填充”系列节点使用 |

### 1.3 参数与表达式

参数显示在节点上和右侧的检查器里。常见类型：

- **浮点数**：左右拖动改变数值，按住 Shift 拖动可微调；单击（不拖动）进入输入状态，可以直接输入数字或**表达式**。表达式支持 `+ - * / % **`、括号、`sin cos tan asin acos atan atan2 sqrt abs floor ceil round exp log pow min max fract sign clamp mix lerp`，常量 `PI TAU E`。按住 Alt 滚动滚轮按步长调整。
  - 表达式里也可以写 `$rnd(0, 1)` 或 `$rndi(1, 5)`：每次放置节点时取一个随机值。
  - 也可以引用全局参数和子图的命名参数（见 1.5）。
- **尺寸**：从 2 的幂中选择（例如 512、1024、2048）。
- **枚举**：下拉列表。
- **布尔**：开关。
- **颜色**：点击打开取色器。
- **渐变**：在检查器里编辑：双击添加色标，拖动移动，右键可删除、反转、均匀分布；插值方式有常数、线性、平滑、三次。
- **曲线、多边形、折线、样条、晶格、像素**：节点上显示缩略图，在检查器里或 2D 预览上编辑：拖动控制点，双击添加或删除点。
- **图像**：“加载图片…”选择本地文件，也可以填写图片网址。

节点标题栏上的骰子图标表示它使用随机种子。右键节点选“新的随机种子”换一个，选“锁定种子”固定它。

### 1.4 子图

**子图**是把一组节点打包成一个节点。选中多个节点后按 Ctrl+G（“编辑 → 打组为子图”），选中的节点就被一个子图节点代替，原来的外部连线自动接到子图的端口上。

- 双击子图节点进入；按 Esc 或点击节点图上方的路径返回上一层；“层次”面板列出整个工程的子图树，点击直接跳转。
- 子图内部的“输入”“输出”节点定义子图的端口，可以在检查器里增删端口、改名和改类型。
- 右键子图选“将子图展开到当前图”可以拆开子图。
- 节点库里的很多节点本身就是子图（例如各种“材质”“风化”节点）。在它上面右键选“设为可编辑（脱离库）”后才能修改内部。
- 子图的“传递种子”选项让内部节点叠加子图的随机种子，复制出的子图因此各不相同。
- “把这个子图复制到所有同名子图”可以把修改同步给工程里其它同名的子图。

### 1.5 参数面板（Remote）与命名参数

**Remote（参数面板）** 节点把内部节点的参数集中成一个面板，子图的参数就是它的 Remote 节点里的控件。在检查器中：

- “关联节点参数…”把某个节点的参数加进面板（一个控件可以同时控制多个节点的参数）；
- 也可以把多组参数值存为一个下拉选项（配置）。

**命名参数**（检查器里的“+ 命名参数”）是子图上的一个数值，子图内的节点可以在表达式里用 `$名字` 引用它。

**全局参数**在“偏好设置 → 全局参数”中定义，所有节点都能以 `$名字` 读取。

### 1.6 缓冲区与迭代

大部分节点只是一段着色器代码，整个节点图最终合并成一个着色器。有些效果需要先把中间结果算成一张图片：

- **缓冲**（杂项/缓冲）把输入渲染成指定分辨率的纹理，后面的节点从纹理采样。模糊、膨胀、距离场等节点内部都用了缓冲区。缓冲区还能降低复杂节点图的计算量。
- **迭代缓冲**（杂项/迭代缓冲）把输出反复送回输入，迭代指定次数，用于扩散、腐蚀等需要多次传递的效果。
- 缓冲区的“32 位”选项使用浮点纹理，可减少色带，但占用更多显存。

### 1.7 其它特殊节点

| 节点 | 用途 |
| --- | --- |
| 转接点 | 整理连线；双击连线即可插入 |
| 传送门（杂项/Aperture 入、出） | 同名的“入”和“出”之间无线连接，减少长连线。右键连线选“替换为传送门” |
| 开关 | 在几组输入之间切换 |
| 注释 | 一个可以写文字、可调整大小的框；“为选中节点添加注释框”自动框住所选节点 |
| 导出 / 自动导出 | 把某个节点的输出存成图片；“自动导出”在输入变化时自动重写选定的文件（需要浏览器支持文件系统访问） |
| 调试 | 显示节点生成的着色器代码 |
| 网格贴图 | 从当前 3D 模型烘焙的位置、法线、切线、曲率、空腔、尖度、环境光遮蔽、弯曲法线、厚度、邻接等贴图（见第 8 节） |
| 自定义着色器 | 自己写 GLSL 代码的节点 |
| 变体（杂项/变体） | 为输入生成多个随机变体，用于让重复的元素各不相同 |

## 2. 界面总览

窗口从上到下是：顶部菜单栏、工程标签页、主区域（中间是节点图，四周是可停靠的面板）、底部状态栏。

- **工程标签页**：可以同时打开多个工程，点击切换，× 关闭。
- **状态栏**：节点库条目数、已编译的着色器数和渲染次数。操作结果（例如“已导出 7 张贴图”）会以提示条短暂显示。

### 2.1 面板

六个面板都可以在“视图 → 面板”中显示或隐藏，拖动面板标题可以把它停靠到别的位置或与其它面板叠成标签页：

| 面板 | 作用 |
| --- | --- |
| 库 | 节点库，按分类浏览和搜索节点 |
| 层次 | 工程的子图树 |
| 3D 材质 | 材质的 3D 预览 |
| 2D 节点输出 | 所选节点输出的大图预览 |
| 参考图 | 放参考图片，从中取色和取渐变 |
| 检查器 | 所选节点的参数、端口、依赖关系和生成的代码 |

“视图 → 重置面板布局”恢复默认布局；“视图 → 面板布局…”可以调整面板宽度、高度，并把当前布局存成预设，之后从“视图”菜单一键切换。

“视图 → 在节点图背后显示 2D 预览 / 3D 预览”把预览铺在节点图背景上。

## 4. 节点库

### 4.1 添加节点

- 在“库”面板中点击节点，或把它拖到节点图上的任意位置；
- 在节点图空白处双击或右键，弹出“添加节点”搜索框：输入名称、分类或别名（如“噪波”“模糊”“砖块”“noise”），用方向键选择，回车添加；
- 从一个端口拖出连线，在空白处松开：搜索框只列出能接上这个端口的节点，添加后自动连好；
- 搜索框顶部是快捷栏，右键库条目选“放入快捷栏”可以把常用节点固定在那里。

库的分类：基础元素（纯色、形状、渐变、文字、图像、SDF 形状、曲线……）、3D（SDF3D 形状和运算、3D 纹理）、图案、噪波、过滤器、变换、工作流、杂项。

### 4.2 自己的库

- 选中一个或多个节点，“编辑 → 将选中节点加入库…”（或右键节点“加入库…”），输入路径式的名称（如 `我的/石材/青砖`），就会出现在库里，保留参数和节点之间的连线。
- 右键库条目可以重命名、修改别名（搜索用的其它名字）、用选中节点更新图标、用选中节点替换、删除。
- “视图 → 库…”管理多个库：新建、显示或隐藏、导出为文件、加载库文件、移除。自己的库保存在浏览器中，换浏览器或清除数据前请先导出。

## 5. 节点图

### 5.1 基本操作

| 操作 | 方式 |
| --- | --- |
| 平移 | 在空白处拖动 |
| 缩放 | 滚轮；右下角按钮可以适应窗口 |
| 选择 | 单击节点；Shift / Ctrl 单击加选；在空白处按住 Shift 拖动框选 |
| 连接 | 从输出端口拖到输入端口。一个输入只能接一根线，输出可以接多根。形成循环的连线会被拒绝 |
| 断开 | 把连线从输入端口拖开，或右键连线选“断开” |
| 插入转接点 | 双击连线，或右键连线选“插入转接点” |
| 删除 | Delete 或 Backspace |
| 进入子图 | 双击子图节点 |
| 返回上一层 | Esc |

右下角的小地图显示整个节点图，可以在上面拖动和缩放。

### 5.2 节点右键菜单

预览输出 N / 隐藏预览、显示 / 隐藏参数、新的随机种子、锁定 / 解锁种子、重命名…、交换输入（Alt+S，交换前两个输入）、复制、连同输入一起复制（Ctrl+Shift+D）、打开子图、编辑节点… / 编辑材质… / 编辑节点图…（Ctrl+E）、设为可编辑（脱离库）、将选中节点打组为子图、将子图展开到当前图、加入库…、删除，以及“选择”“对齐”子菜单：

- 选择：全选、取消选择、反选、最小化 / 还原选中节点（Ctrl+M）、为选中节点添加注释框；
- 对齐：左对齐、居中对齐、右对齐、顶部对齐、拉直连线。

### 5.3 预览缩略图

节点上的缩略图按需显示：右键节点选“预览输出 N”。节点图工具栏上的“全部预览”在每个节点上显示预览。预览分辨率在偏好设置中调整。

### 5.4 查找节点

Ctrl+F（“编辑 → 查找节点…”）在整个工程（包括所有子图）里按名称或类型查找节点，回车跳过去。

### 5.5 编辑节点

Ctrl+E 打开节点编辑器，可以修改节点的着色器模型：

- **一般**：名称、说明、参数（名称、标签、类型、范围、默认值、说明）、输入（类型、未连接时的默认值、是否作为函数、端口组）、包含的其它节点的全局函数；
- **输出**：每个输出的类型、表达式和说明；
- **主要代码 / 实例函数 / 全局函数**：GLSL 代码，写法见 [节点库维护](节点库维护.md) 中的“代码里的 `$` 关键字”；
- **预览 / 导出**（材质节点）：3D 预览着色器和各导出目标的文件。

点“应用”时会编译每个输出，有错误会提示。库里的节点修改后会成为工程里独立的节点，不影响库。

检查器里的“着色器模型 → 以 JSON 编辑模型”可以直接编辑 JSON。

## 6. 检查器与预览

### 6.1 检查器

选中一个节点，检查器显示：

- **参数**：所有参数的编辑控件；随机种子和“随机化”；可变端口数量（泛型输入数）。
- **输入 / 输出**：每个端口的名称、类型、来自哪个节点、连到哪些节点、未连接时的默认值。
- **纹理贴图**（材质节点）：材质的每张贴图。
- **上游**：这个节点由哪些节点计算而来的依赖树，可以跨子图点击跳转。
- **生成的 GLSL**：所选输出的代码片段或完整着色器，及其 uniform 的实时值，可以复制。
- **着色器模型**：参数在代码中的实际取值、每个输入的默认值、主要代码、实例代码、全局代码、包含的节点。
- 没有选中节点时显示**节点图分析**：节点数、连线数、子图数和节点类型统计。

子图节点还会显示它的参数面板、命名参数，以及子图输入、输出端口的编辑。

### 6.2 2D 预览

“2D 节点输出”面板显示所选节点的输出大图：

- 中键或 Shift+拖动平移，滚轮或 Ctrl+拖动缩放；“重置视图”恢复。
- “视图 ▾”：单张或平铺显示（检查接缝）、过滤方式、低分辨率预览、参考线和网格、Alpha 显示、透明棋盘格的亮度和大小、控制点开关。
- 很多节点在 2D 预览上有操控点：形状的位置和大小、渐变方向、多边形的顶点等，直接拖动即可。像素参数可以在这里绘制：左键用调色板最后一种颜色，右键或按住 Shift 用第一种。
- 锁图标把预览固定在当前节点上，之后选择其它节点也不会切换。
- 输出端口有多个时，可在上方选择要看的输出。
- “导出 ▾”：按分辨率存成图片文件（文件名可用 `$node`、`$output`、`$resolution`、`$project`），“导出到参考图”，以及动画导出和 TAA 渲染。

### 6.3 3D 预览

“3D 材质”面板显示材质在模型上的效果：

- 拖动：环绕；Ctrl+拖动：旋转模型；右键拖动：平移；滚轮：缩放；Ctrl+滚轮：视野。
- **模型**：立方体、圆柱、球、平面、棱柱、圆环、Suzanne 猴头、枕头，或“加载模型…”导入 `.obj`、`.glb`、`.gltf`、`.fbx`。每个模型可以设置 UV 缩放、倒角等参数，以及“细分”（需要置换时打开）。
- **环境**：几种 HDR 环境，或纯色背景；“环境编辑器…”可以复制内置环境后修改，或上传自己的 `.hdr`。
- **后期处理**：色调映射（AgX、Reinhard、Filmic、ACES 等）、辉光、调整、景深。
- **相机与灯光**：重置相机、视野、阳光阴影。
- 面板角落可以调预览贴图分辨率；“深度”开关把深度贴图作为置换。
- 3D PBR 材质、光线步进材质和天空材质在 3D 空间中求值，预览由光线追踪直接显示（拖动旋转、滚轮缩放），可以切换球体和立方体。

### 6.4 参考图

“参考图”面板：添加、拖入或粘贴参考图片，滚轮缩放、拖动平移。面板下方有几个颜色槽和渐变槽：点选一个槽，再在图片上点击取色（拖动时取经过区域的平均色）；渐变槽则沿拖动的路径记录颜色生成渐变。把槽拖到节点的颜色或渐变参数上即可使用。“显示未过滤的像素”用最近邻方式放大图片。2D 预览的“导出到参考图”可以把节点输出放进来对比。

### 6.5 色调节点的直方图

“色调”类节点（色调映射、色阶等）在检查器里显示输入的直方图，“自动”按直方图调整输入色阶。

## 7. Easy SDF

“基础元素/Easy SDF”节点是一个 SDF 场景构建器：在一个节点里用场景树搭建 2D 或 3D 形状，不必连很多 SDF 节点。

- 选中节点后，检查器显示场景树。“添加到 …”添加元素：2D/3D 形状、布尔、平滑布尔、变形（弯曲、扭转、重复……）、颜色和纹理元素。
- 元素可以上移、下移、移入上方元素、移出父元素、显示或隐藏、重命名；复制（Ctrl+C）、剪切（Ctrl+X）、粘贴（Ctrl+V）。
- 每个元素的参数可以改为 GLSL 表达式（例如 `$scale*0.5`），由节点参数驱动。
- “SDF 构建器…”打开大窗口：左边场景树，中间带操控手柄的 2D/3D 预览（拖动旋转，Shift+拖动平移，滚轮缩放；“局部”让手柄对齐元素），右边元素参数。“+ 参数”添加节点参数，它们显示在节点上，在表达式中以 `$名称` 使用。点“应用”或“确认”写回节点。

## 8. 绘制模式

“文件 → 新建绘制项目”选择模型（内置形状或 `.obj`、`.glb`、`.gltf`、`.fbx` 文件）和贴图尺寸，进入绘制模式。模型必须有 UV 展开。

**视图操作**：左键拖动绘制，右键拖动旋转，中键拖动平移，滚轮缩放，Shift+拖动调整笔刷大小和硬度，Ctrl+拖动调整图案。“2D 贴图视图”可以直接在贴图空间里画（滚轮缩放，中键平移）。

**工具**：自由点、自由线、直线、印章、取色、ID 遮罩，以及“擦除”“填充”。绘制方式有“视图空间”和“贴图空间”（透过视图投影到贴图）。ID 遮罩工具需要先在工具选项中“加载 ID 贴图…”，点击模型选择要绘制的区域。

**笔刷设置**：尺寸、硬度、不透明度、间距、角度、图案缩放、抖动；数位板笔压可以控制尺寸、不透明度和硬度。

**笔刷**：笔刷就是节点图，绘制时下方的节点编辑器显示的就是当前笔刷，可以直接修改；笔刷的参数面板显示在右侧。“+ 保存笔刷”把当前笔刷存进笔刷库，可以搜索。

**图层**：
- 绘制图层（“+ 绘制”）：五个通道——反照率、金属度/粗糙度、自发光、法线、深度/AO；
- 程序图层（“+ 程序”）：由笔刷节点图填满，修改节点图就更新；
- 遮罩（“+ 遮罩”）：作用于所在图层。
图层可以嵌套、上下移动、显示或隐藏、复制、删除，每个通道有自己的不透明度。

**撤销**：按图层逐笔撤销（Ctrl+Z）和重做（Ctrl+Shift+Z）。

**工程设置**：贴图尺寸、凹凸强度。

**保存与导出**：“保存绘制工程”在浏览器里下载 zip（包含 `.mmpp` 工程、各图层 PNG 和模型；用内置模型时只记模型名），在 Mac 应用里保存到文件，之后再保存直接写回这个文件；“打开绘制工程…”可以选这个 zip，也可以把 Material Maker 的 `.mmpp` 与它的图层 PNG、模型一起选上。“导出绘制的贴图 (zip)”导出合成后的贴图；“导出绘制的材质到”可以直接使用第 9 节的各引擎导出目标。

**网格贴图**：绘制需要的网格贴图（位置、法线、切线、曲率、环境光遮蔽、弯曲法线、厚度、邻接、接缝）在打开模型时自动烘焙。材质模式下，“网格贴图”节点使用 3D 预览中当前显示的模型，可以用来做边缘磨损、缝隙积灰等依赖模型形状的效果。烘焙参数（尺寸、每像素光线数、AO 距离和偏移、降噪半径）在偏好设置中。

## 9. 导出

### 9.1 材质类型

| 材质节点 | 适用 | 导出内容 |
| --- | --- | --- |
| 静态 PBR 材质 | 绝大多数情况 | 贴图 + 材质文件 |
| 静态 PBR 材质（置换） | 需要置换的模型 | 同上，3D 预览以置换显示深度 |
| 动态 PBR 材质 | 动画、与分辨率无关或不重复的材质 | 引擎着色器代码 + 必要的缓冲区贴图 |
| 3D PBR 材质 | 按物体 3D 位置计算的材质（无需 UV） | 引擎着色器代码 |
| 光线步进材质 | 用 SDF 定义的立体形状 | 引擎着色器代码 |
| 动态天空材质 | Godot 4 天空 | 天空着色器 |
| 动态无光照材质 | 无光照（UI、特效） | 着色器 |

“文件 → 导出…”按框架分组列出当前材质支持的全部导出目标。导出结果是一个 zip，解压后按下面的方法导入。贴图尺寸取材质节点的“尺寸”参数，导出对话框里也可以临时修改。

### 9.2 Blender

导出 **Blender** 得到各张贴图：反照率、粗糙度、金属度、法线（OpenGL）、置换、次表面散射、自发光、环境光遮蔽。导入方法：

1. 在 Blender 中选中物体，新建材质（使用“原理化 BSDF”）。
2. 在着色器编辑器里为每张贴图添加“图像纹理”节点：反照率接“基础色”；粗糙度、金属度、法线、置换等非颜色贴图把色彩空间设为“非彩色”；粗糙度接“糙度”，金属度接“金属度”；法线贴图经“法线贴图”节点接“法向”；自发光接“自发光颜色”。
3. 需要置换时，把置换贴图经“置换”节点接到材质输出的“置换”，并在材质设置里把置换方式设为“置换和凹凸”（Cycles）。

更省事的方法是导出 **glTF（.glb）**，在 Blender 中“文件 → 导入 → glTF 2.0”，材质会自动接好。

### 9.3 Unity

三个目标：**Unity/3D**（内置渲染管线）、**Unity/URP**、**Unity/HDRP**。zip 里有 `.mat` 材质、贴图和对应的 `.meta` 文件（已设置好法线贴图等导入选项）。

把解压出的文件夹整个拖进 Unity 工程的 `Assets` 目录，Unity 会识别材质并关联贴图，再把材质拖到物体上即可。请选与工程渲染管线一致的目标。

动态材质、3D 材质、光线步进材质导出为 `.shader` 着色器加 `.mat`。也可以导出 glTF，配合 glTFast 插件导入。

### 9.4 Godot

- **Godot 4 Standard / Godot 4 ORM**：`.tres` 材质（StandardMaterial3D / ORMMaterial3D）和贴图；
- **Godot 3 Spatial**：Godot 3 的 SpatialMaterial；
- 动态材质等导出 `.gdshader` 着色器和 `ShaderMaterial` 的 `.tres`；无光照材质有 CanvasItem（2D）和 Spatial（3D）两种；天空材质导出 Godot 4 天空着色器。

把解压出的文件夹放进 Godot 工程目录（`res://` 下），Godot 自动导入贴图，然后把 `.tres` 拖到网格的“材质覆盖”或“表面材质覆盖”上。

### 9.5 Unreal Engine

- **Unreal Engine 5**：贴图加一个 Python 脚本（`.py`）。在 UE5 中启用“Python Editor Script Plugin”，把导出的文件放进一个文件夹，然后在“工具 → 执行 Python 脚本”中运行这个脚本，它会导入贴图并创建材质。
- **Unreal Engine 4**：贴图加 `.mm2ue` 文件，需要配合 Material Maker 的 UE4 导入插件使用；没有插件时，可以只导入贴图：把 PNG 拖进内容浏览器，新建材质，反照率接“基础颜色”，ORM 贴图的 R、G、B 分别接“环境光遮蔽”“粗糙度”“金属感”（该贴图取消 sRGB），法线贴图接“法线”。

Unreal 使用 DirectX 法线方向；导出目标已经按 Unreal 的约定生成。

### 9.6 Cocos Creator

“Cocos Creator 3.x 材质”导出一个文件夹：基于内置 `builtin-standard` 着色器的 `.mtl` 材质、贴图和全部 `.meta` 文件。把文件夹直接放进 Cocos 工程的 `assets` 目录，编辑器刷新后即可把材质拖到 MeshRenderer 上。

也可以导出 glTF（.glb），Cocos 会连同材质一起导入。

### 9.7 glTF（.glb）

“二进制 glTF（.glb）”导出一个带材质的模型文件（平面、球体或立方体），贴图嵌在文件里，符合 glTF 2.0 标准（反照率、ORM、法线、自发光）。Cocos、Blender、Godot、Unity（glTFast）、Unreal、three.js、Babylon.js 都能直接导入。在其它引擎里可以只保留它的材质，赋给自己的模型。

另有 **GLTF/Plane** 目标，导出 `.gltf` 文本文件加单独的 PNG 贴图。

### 9.8 m3e-canvas-pro

“m3e 材质文件”导出一个 m3e 材质包，用于 m3e-canvas-pro 中 UI 表面的材质：可以保持原样，也可以按主题换色。选项：平铺尺寸、分辨率、光照方向和高度、是否包含 PBR 贴图、是否包含工程（以便再次编辑）。文件格式见仓库中的 `docs/m3e-material.md`。

### 9.9 贴图包

“全部贴图（zip）”或“文件 → 导出材质贴图（zip）”把每张贴图存为 PNG：反照率、ORM、法线（OpenGL 和 DirectX 两种）、高度、环境光遮蔽、金属度、粗糙度、自发光、次表面散射，适用于任何其它工具。

法线贴图方向：Blender、Unity、Godot、glTF、Cocos 使用 OpenGL（Y 向上）；Unreal、3ds Max 等使用 DirectX（Y 向下）。导入其它工具时选对应的那张。

## 11. 偏好设置

点击右上角的 ⚙ 或“编辑 → 偏好设置”：

- **一般**：语言；界面缩放（0 为自动）；关闭项目时确认；离开页面前若有未保存的修改则确认；记住动画导出设置；显示对话框时调暗背景；工作时自动保存到浏览器。
- **主题**：基础颜色、强调色、对比度，可恢复默认主题。
- **图形**：注释节点自动适应选区大小；节点上显示最小化按钮、关闭按钮；传送门标签的位置；新材质的尺寸；节点预览分辨率。
- **3D 预览**：预览分辨率、细分精度、帧率上限。
- **网格贴图**：网格贴图尺寸、每像素光线数、环境光遮蔽光线距离和偏移、降噪半径。
- **全局参数**：所有节点都能以 `$名称` 读取的值。

设置保存在浏览器中。

## 12. 常见问题

**预览是黑的或显示“渲染器未就绪”。** 需要支持 WebGL2 的浏览器（最新版 Chrome、Edge、Firefox、Safari）。检查浏览器是否开启了硬件加速；在远程桌面或虚拟机中 WebGL 可能不可用。

**某个节点很慢，或整个页面卡住。** 降低“节点预览分辨率”和“3D 预览分辨率”，关闭“全部预览”；在复杂的节点前加一个“缓冲”节点，让后面的节点从纹理采样；减少模糊、迭代缓冲的迭代次数。

**改了节点后提示编译失败。** 检查器的“生成的 GLSL”和节点编辑器“应用”时的错误信息会指出出错的行。常见原因是参数名或输入名写错、类型不匹配（`float` 和 `vec3` 混用）。

**导入引擎后法线方向反了（凹凸颠倒）。** 换用另一种法线方向的贴图（见 9.9），或在引擎里翻转法线贴图的绿色通道。

**导入引擎后颜色发灰或过亮。** 反照率和自发光是 sRGB 颜色贴图；粗糙度、金属度、ORM、法线、高度应设为线性（非彩色 / 取消 sRGB）。

**有接缝。** 2D 预览中切换到平铺显示检查。大多数生成节点是可平铺的；“变换”“扭曲”等节点的边缘模式要选“重复”；导入的图片本身不可平铺时可用“生成可平铺”类节点处理。

**3D 预览中模型是平的、看不出置换。** 打开模型的“细分”和预览面板的“深度”开关，或使用“静态 PBR 材质（置换）”。

**自动保存、自己的库和环境丢了。** 它们都保存在当前浏览器中：清除网站数据、换浏览器或使用隐私窗口都会丢失。请定期保存 `.ptex` 并导出自己的库。

**打不开 Material Maker 的文件。** `.ptex` 工程与 Material Maker 通用；绘制工程需要 `.mmpp` 连同它引用的图层 PNG 和模型一起选上。如果文件用到了本程序节点库里没有的节点类型（例如 Material Maker 新版本加入的节点），这些节点无法加载；可以按[节点库维护](节点库维护.md)的方法把节点加进 `library/`。

**“自动导出”不能写文件。** 持续写文件需要浏览器支持文件系统访问（Chrome、Edge）；其它浏览器只能下载当前图像。
